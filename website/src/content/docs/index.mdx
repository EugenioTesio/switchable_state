## Why switchable_state

<CardGrid stagger>
	<Card title="Screens read, never receive" icon="seti:pipeline">
		Every widget gets its state from the nearest `StateScope` by a declared key. Nothing is passed
		between screens through constructors.
	</Card>
	<Card title="Swap the library, keep the app" icon="random">
		`StateScope(adapter: RiverpodStateAdapter())` becomes `CubitStateAdapter()`, and the whole app
		runs on flutter_bloc. Same screens, same tests.
	</Card>
	<Card title="Lifetimes you can see" icon="seti:clock">
		A store is app-wide, shared by a group of routes, or owned by one route. Its owner closes it, the
		way Riverpod's `autoDispose` or `BlocProvider(create:)` do.
	</Card>
	<Card title="Side effects without rebuilds" icon="rocket">
		`StateListener` shows a snack bar or navigates when a store changes, like `BlocListener` or
		`ref.listen`, and never mid-build.
	</Card>
	<Card title="Families and observers" icon="magnifier">
		`StateFamily` gives one store per argument, and a `StateObserver` sees every store the app
		creates, changes and closes.
	</Card>
	<Card title="Proven by one test suite" icon="approve-check">
		The same conformance suite runs against every official adapter, and you can run it against your
		own with `switchable_state_test`.
	</Card>
	<Card title="No dependency needed" icon="puzzle">
		`switchable_state_value_notifier` runs the same contract on Flutter's own `ValueNotifier`, for
		tests, prototypes or apps that want no state library.
	</Card>
</CardGrid>

## Install

Add the contract and the adapter for the library you use. Your app depends only on that library.

## Packages on pub.dev

All eight packages are published on [pub.dev](https://pub.dev/packages?q=switchable_state), with API references generated from their doc comments.

| Package | What it contains | Version |
| --- | --- | --- |
| [switchable_state](https://pub.dev/packages/switchable_state) | `StateAdapter`, `StateStore`, `StateScope`, `AppState`, `StateStoreOwner` | <PubBadge pkg="switchable_state" /> |
| [switchable_state_bloc](https://pub.dev/packages/switchable_state_bloc) | `CubitStateAdapter` (flutter_bloc) | <PubBadge pkg="switchable_state_bloc" /> |
| [switchable_state_getx](https://pub.dev/packages/switchable_state_getx) | `GetXStateAdapter` (get) | <PubBadge pkg="switchable_state_getx" /> |
| [switchable_state_mobx](https://pub.dev/packages/switchable_state_mobx) | `MobXStateAdapter` (mobx, flutter_mobx) | <PubBadge pkg="switchable_state_mobx" /> |
| [switchable_state_provider](https://pub.dev/packages/switchable_state_provider) | `ProviderStateAdapter` (provider) | <PubBadge pkg="switchable_state_provider" /> |
| [switchable_state_riverpod](https://pub.dev/packages/switchable_state_riverpod) | `RiverpodStateAdapter` (flutter_riverpod) | <PubBadge pkg="switchable_state_riverpod" /> |
| [switchable_state_value_notifier](https://pub.dev/packages/switchable_state_value_notifier) | `ValueNotifierStateAdapter` (Flutter only) | <PubBadge pkg="switchable_state_value_notifier" /> |
| [switchable_state_test](https://pub.dev/packages/switchable_state_test) | `stateStoreContract`, the conformance suite for adapters | <PubBadge pkg="switchable_state_test" /> |
